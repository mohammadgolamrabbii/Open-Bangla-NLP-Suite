# Open Bangla NLP & AI Suite

Structured open-source Bangla datasets curated by **Mohammad Golamrabbii**:
- `morphology/bangla_morphology_index.jsonl`: Root/lemma/inflection breakdown across verified NFC Bangla words
- `idioms-proverbs/bangla_idioms_proverbs.jsonl`: Bangla idioms, proverbs, homophones, and one-word substitutions
- `etymology/bangla_etymology_map.jsonl`: Word-origin map (Sanskrit/Tatsama, Prakrit/Tadbhava, Arabic, Persian, English, Portuguese)
- `eval-suite/bangla_eval_benchmark.jsonl`: Deterministic LLM benchmark for Bangla orthography, morphology, idioms, homophones, and Bangla-Hindi cognates
